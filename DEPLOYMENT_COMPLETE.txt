STEP-BY-STEP DEPLOYMENT INSTRUCTIONS

═════════════════════════════════════════════════════════════════════════════════

FRONTEND DEPLOYMENT (Vercel)
───────────────────────────

1. Install Vercel CLI (if not already installed):
   npm install -g vercel

2. Deploy frontend:
   cd frontend
   vercel --prod

3. Follow Vercel prompts:
   - Link to existing project or create new
   - Select `frontend` as root directory
   - Deploy

4. Add environment variable in Vercel dashboard:
   Key: NEXT_PUBLIC_API_URL
   Value: https://interviewforge-api.onrender.com
   (Update after backend deployment)

5. Your frontend is now live at:
   https://interviewforge.vercel.app


BACKEND DEPLOYMENT (Render)
──────────────────────────

1. Go to https://render.com/dashboard

2. Click "New +" → "Web Service"

3. Connect GitHub repository:
   - Select your Interview_Systemm repo
   - Select project-implementation branch

4. Configure service:
   - Name: interviewforge-api
   - Root Directory: backend
   - Environment: Python 3.11
   - Build Command: pip install -r requirements.txt
   - Start Command: uvicorn app.main:app --host 0.0.0.0 --port $PORT

5. Add Environment Variables (copy all from BACKEND_ENV_VARS below)

6. Click "Create Web Service"

7. Wait for deployment to complete (~5 minutes)

8. Your backend is now live at:
   https://interviewforge-api.onrender.com


DATABASE SETUP (PostgreSQL)
──────────────────────────

Option A: Neon PostgreSQL (Recommended)
  1. Go to https://neon.tech
  2. Sign up and create project
  3. Create database: "interviewforge"
  4. Get connection string
  5. Add to backend environment: DATABASE_URL

Option B: AWS RDS
  1. Create RDS PostgreSQL instance
  2. Enable public access
  3. Save connection string
  4. Add to backend environment: DATABASE_URL

Initialize database:
  connect to Render shell:
    cd backend
    alembic upgrade head
    python scripts/init_db.py


REDIS SETUP
──────────

Option A: Upstash (Recommended)
  1. Go to https://upstash.com
  2. Create Redis database
  3. Copy REDIS_URL
  4. Add to backend environment: REDIS_URL

Option B: Redis Cloud
  1. Go to https://redis.com/try-free
  2. Create database
  3. Copy connection string
  4. Add to backend environment: REDIS_URL


AWS S3 SETUP (Optional but Recommended)
──────────────────────────────────────

1. Create S3 bucket: interviewforge-assets
2. Enable CORS
3. Create IAM user with S3 access
4. Add to backend environment:
   AWS_ACCESS_KEY_ID
   AWS_SECRET_ACCESS_KEY

TROUBLESHOOTING

═════════════════════════════════════════════════════════════════════════════════

Frontend won't deploy:
  • Check Node version: node --version (should be 18+)
  • Clear cache: rm -rf .next node_modules
  • Rebuild: npm install && npm run build

Backend crashes:
  • Check Render logs for errors
  • Verify DATABASE_URL is correct
  • Ensure all env vars are set
  • Check Python version (should be 3.11+)

Can't connect frontend to backend:
  • Verify NEXT_PUBLIC_API_URL is correct in Vercel
  • Check backend health: curl https://api.example.com/health
  • Check CORS settings in backend
  • Verify both are deployed and running

Database connection error:
  • Test connection string locally
  • Verify database is public (if needed)
  • Check credentials
  • Ensure DATABASE_URL format is correct
