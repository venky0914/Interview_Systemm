===============================================================================
                    DEPLOYMENT CHECKLIST - EASY VERSION
===============================================================================

BEFORE YOU START:
[ ] You have GitHub account (with repo access to Interview_Systemm)
[ ] You have Vercel account (or create at vercel.com)
[ ] You have Render account (or create at render.com)

===============================================================================
STEP 1: DEPLOY FRONTEND TO VERCEL (5 minutes)
===============================================================================

[ ] 1. Go to https://vercel.com and login with GitHub
[ ] 2. Click "Add New" → "Project"
[ ] 3. Search for "Interview_Systemm" and click to import
[ ] 4. Set Project Name: "interviewforge"
[ ] 5. Set Root Directory: "frontend" (click Edit)
[ ] 6. Add Environment Variable:
      Key: NEXT_PUBLIC_API_URL
      Value: http://localhost:8000
[ ] 7. Click "Deploy"
[ ] 8. Wait for build (2-3 minutes)
[ ] 9. Copy your frontend URL: https://interviewforge.vercel.app

RESULT: Frontend is LIVE at https://interviewforge.vercel.app ✓

===============================================================================
STEP 2: DEPLOY BACKEND TO RENDER (10 minutes)
===============================================================================

[ ] 1. Go to https://render.com and login with GitHub
[ ] 2. Click "New" → "Web Service"
[ ] 3. Click "Connect repository"
[ ] 4. Search for "Interview_Systemm" and connect it
[ ] 5. Fill in configuration:
      Name: interviewforge-api
      Environment: Python 3.11
      Branch: project-implementation
      Root Directory: backend
      Build Command: pip install -r requirements.txt
      Start Command: uvicorn app.main:app --host 0.0.0.0 --port $PORT
[ ] 6. Add Environment Variables (see list below)
[ ] 7. Click "Deploy Web Service"
[ ] 8. Wait for build (5-10 minutes)
[ ] 9. Copy your backend URL: https://interviewforge-api.onrender.com

ENVIRONMENT VARIABLES FOR BACKEND:
[ ] APP_NAME = InterviewForge AI
[ ] APP_ENV = production
[ ] DEBUG = false
[ ] SECRET_KEY = (any random string, e.g., "your-secret-12345")
[ ] ALLOWED_ORIGINS = https://interviewforge.vercel.app
[ ] DATABASE_URL = (leave empty for now)
[ ] REDIS_URL = (leave empty for now)
[ ] JWT_SECRET_KEY = (any random string)
[ ] JWT_ALGORITHM = HS256
[ ] ACCESS_TOKEN_EXPIRE_MINUTES = 30
[ ] REFRESH_TOKEN_EXPIRE_DAYS = 7
[ ] (Leave Google, Gemini, AWS keys empty for now)

RESULT: Backend is LIVE at https://interviewforge-api.onrender.com ✓

===============================================================================
STEP 3: CONNECT FRONTEND TO BACKEND (2 minutes)
===============================================================================

[ ] 1. Go back to Vercel (https://vercel.com)
[ ] 2. Click on your "interviewforge" project
[ ] 3. Click "Settings" → "Environment Variables"
[ ] 4. Find "NEXT_PUBLIC_API_URL" 
[ ] 5. Change value from "http://localhost:8000" to "https://interviewforge-api.onrender.com"
[ ] 6. Click "Save"
[ ] 7. Click "Deployments"
[ ] 8. On latest deployment, click "..." menu
[ ] 9. Click "Redeploy"
[ ] 10. Wait for redeploy to finish (1-2 minutes)

RESULT: Frontend now knows backend URL ✓

===============================================================================

===============================================================================

[ ] 2. You should see login page (if not, check troubleshooting)
[ ] 3. Open API docs: https://interviewforge-api.onrender.com/docs

[ ] 6. Fill email and password
[ ] 7. Click "Sign Up"
[ ] 8. If no error, it worked! ✓

IF SOMETHING GOES WRONG:
===============================================================================

Frontend won't load:
[ ] Check Vercel deployment logs (click "Deployments" tab)
[ ] Make sure root directory is "frontend"
[ ] Try redeploying

Backend won't load:
[ ] Check Render build logs
[ ] Make sure root directory is "backend"
[ ] Check that Python 3.11 is selected

Can't sign up:
[ ] Check backend is running: visit https://interviewforge-api.onrender.com/docs
[ ] Check frontend environment variable has correct backend URL
[ ] Check browser console for errors (F12)
